## 🚀 Sobre

Site portfólio minimalista e imersivo, com estética inspirada em **ensō** e **hanko** japoneses.  
Feito para ser rápido, acessível e agradável de navegar — com animações suaves, glassmorphism, paralaxe e tipografia refinada.

## 🏃 Rodando localmente

```bash
# Clone o repositório
git clone https://github.com/ranzouu/ranzouu.github.io.git
cd ranzouu.github.io

# Instale as dependências
npm install

# Inicie o servidor de desenvolvimento
npm run dev

# Gere o build de produção
npm run build

# Faça o preview do build
npm run preview
```

Abra `http://localhost:4321` para ver o site em ação.

---

## 🌐 Deploy

O deploy é automático via **GitHub Pages** a cada push na branch principal.

1. Vá em **Settings → Pages** do repositório.  
2. Em **Build and deployment**, selecione **Source: GitHub Actions**.  
3. O workflow do repositório cuida do build e do deploy automaticamente.

Live: [https://ranzouu.github.io](https://ranzouu.github.io)
